# Інформаційна архітектура та користувацькі сценарії UniFlow

## Sitemap

Карта сайту UniFlow відображає ієрархію основних розділів інформаційної системи та їхніх функціональних елементів.

Головна навігація містить шість розділів: Today Dashboard, Subjects, Tasks, Week Calendar, Focus Mode та Progress. Кожен розділ відповідає за окрему частину процесу організації навчання.

Інформаційна архітектура побудована за принципом розділення функцій: керування навчальними предметами, керування завданнями, планування часу, концентрація та аналіз результатів.

## User Flow

Користувацький сценарій описує основний шлях взаємодії студента із системою UniFlow: створення семестру, додавання предмета, створення завдання, планування його виконання, запуск фокус-сесії та перегляд прогресу.

Схема містить альтернативні сценарії й перевірки коректності введених даних. У випадку помилки користувач отримує повідомлення та може повернутися до форми для виправлення.

Головна мета User Flow — забезпечити послідовну та зрозумілу взаємодію із системою, мінімізувати кількість зайвих дій і продемонструвати зв'язки між основними функціями продукту.
