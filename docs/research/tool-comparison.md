# Порівняльний аналіз інструментів UI/UX-проєктування для UniFlow

**Проєкт:** UniFlow — студентський планувальник навчання  
**Дисципліна:** Основи дизайну UI/UX  
**Практична робота №2**  
**Дата аналізу:** 21.10.2026

## 1. Мета дослідження

Метою порівняльного аналізу є визначення підходу до створення інтерактивного прототипу UniFlow, який забезпечить відповідність функціональним вимогам продукту, узгодженість компонентів інтерфейсу та можливість подальшого розвитку системи.

Розглянуто чотири інструменти: Figma, Google Stitch, v0 та Lovable. Дослідження проведено на основі офіційної документації та заявлених функціональних можливостей платформ.

## 2. Критерії порівняння

Для оцінювання інструментів визначено такі критерії:

1. **Створення інтерфейсів:** підтримка макетів, сторінок і візуальних компонентів.
2. **Можливості штучного інтелекту:** генерація дизайну або коду за текстовими інструкціями.
3. **Інтерактивне прототипування:** можливість демонструвати переходи та реакції інтерфейсу.
4. **Робота з кодом:** можливість отримати й редагувати вихідний код.
5. **Дизайн-система:** підтримка повторно використовуваних компонентів, стилів і станів.
6. **Розширюваність:** можливість перетворити прототип на функціональний застосунок.
7. **Відповідність UniFlow:** придатність для реалізації предметів, завдань, календаря, таймера та статистики.

## 3. Характеристика інструментів

### 3.1. Figma

Figma — платформа для візуального проєктування інтерфейсів, створення дизайн-систем та інтерактивних прототипів.

**Переваги:**

- точне візуальне налаштування макетів;
- компоненти, варіанти компонентів і змінні дизайну;
- інтерактивне прототипування;
- можливості командної співпраці;
- інструменти взаємодії між дизайном і розробкою.

**Обмеження для UniFlow:**

Візуальний прототип у Figma сам собою не замінює реалізацію застосунку з повноцінним керуванням навчальними завданнями, локальним збереженням даних і робочим таймером. Для цього потрібен додатковий етап розробки або використання інших засобів.

**Висновок:** Figma є доцільним рішенням для детального дизайну та демонстрації UX, але для вимоги створити UI-kit безпосередньо в React і надалі розвивати його до ПЗ3 було обрано інший основний процес.

### 3.2. Google Stitch

Google Stitch — AI-орієнтований інструмент для генерації та опрацювання інтерфейсів.

**Переваги:**

- формування дизайну на основі текстового опису;
- можливість використовувати візуальні матеріали як контекст;
- швидке дослідження різних варіантів інтерфейсу;
- інтерактивне коригування AI-результатів;
- засоби передачі створених рішень до процесу розробки.

**Обмеження для UniFlow:**

Генерація макетів або frontend-коду не гарантує правильної реалізації конкретних бізнес-правил, таких як пріоритетність навчальних завдань, каскадне видалення предметів, збереження стану фокус-сесій чи розрахунок прогресу. Ці можливості потребують окремого проєктування, реалізації та перевірки.

**Висновок:** Stitch придатний для швидкого дослідження візуальних концепцій, однак для UniFlow потрібен безпосередній контроль структури React-проєкту.

### 3.3. v0

v0 — AI-інструмент, орієнтований на генерацію вебінтерфейсів і коду застосунків.

**Переваги:**

- створення інтерфейсів за текстовими інструкціями;
- підтримка розробки на React і TypeScript;
- можливість редагувати згенерований код;
- інтеграція з GitHub;
- засоби попереднього перегляду та публікації.

**Обмеження для UniFlow:**

Згенеровані компоненти необхідно адаптувати до архітектури конкретного проєкту, його дизайн-токенів, типів даних та наявних Storybook stories. Автоматичне створення інтерфейсу не гарантує виконання всіх вимог до доступності, тестування й управління станом.

**Висновок:** v0 добре відповідає підходу AI-first для React-інтерфейсів. Його можна розглядати як альтернативу для швидкого створення окремих сторінок UniFlow або їхніх візуальних варіантів.

### 3.4. Lovable

Lovable — AI-платформа для створення та розгортання вебзастосунків через інструкції природною мовою.

**Переваги:**

- швидке створення функціональних вебзастосунків;
- підтримка frontend і backend-частин;
- можливості інтеграції баз даних та інших сервісів;
- редагований вихідний код;
- синхронізація з GitHub.

**Обмеження для UniFlow:**

Для навчального завдання, де потрібно демонструвати власну архітектуру компонентів, окремий UI-kit і Storybook, важливо контролювати структуру створеного коду й процес його перевірки. Генерація готового застосунку не усуває потреби в ручному аудиті реалізації.

**Висновок:** Lovable є корисним інструментом для швидкого створення функціонального MVP, проте для цілей цієї практичної роботи обрано процес із безпосереднім контролем React-коду.

## 5. Обґрунтування вибраного підходу

Для UniFlow обрано **Variant B — AI-assisted code-first прототипування**.

У практичній реалізації використано:

- **ChatGPT/Claude** — для підготовки й уточнення коду компонентів, пояснення архітектурних рішень і допомоги з усуненням помилок;
- **React і TypeScript** — для реалізації інтерактивного інтерфейсу;
- **Vite** — для організації локального середовища розробки;
- **Storybook** — для незалежної демонстрації UI-компонентів та їхніх станів;
- **CSS design tokens** — для централізованого керування візуальним стилем;
- **React Router** — для навігації між екранами;
- **React Context і localStorage** — для спільного стану та локального збереження даних;
- **Git** — для контролю версій.

Вибраний підхід дозволив розробити шість основних екранів: Today, Subjects, Tasks, Week, Focus і Progress. Компоненти Button, Input, Select, Badge та Card були організовані як повторно використовувані елементи UI-kit із відповідними Storybook stories.

На відміну від суто візуального прототипування, code-first підхід дає можливість перевіряти не лише вигляд інтерфейсу, а й реальну взаємодію користувача із системою.

Завдяки тому, що інтерфейс уже реалізований у React, надалі можна вдосконалювати архітектуру, тестування, доступність і збереження даних без повної повторної реалізації проєкту.

## 6. Висновок

Проведений аналіз показав, що розглянуті інструменти вирішують різні завдання процесу UI/UX-проєктування.

Figma забезпечує детальний контроль візуального дизайну. Google Stitch прискорює пошук дизайнерських рішень за допомогою AI. v0 і Lovable дозволяють швидко створювати інтерфейси та робочі вебзастосунки.

Для UniFlow було обрано AI-assisted code-first підхід, оскільки він відповідає потребі створити не лише інтерактивний прототип, а й незалежний React UI-kit, Storybook-документацію та основу для подальшого розвитку продукту.

При цьому AI-генерація розглядається як допоміжний інструмент. Остаточна якість застосунку визначається перевіркою функціональності, дизайну, доступності та відповідності вимогам PRD.
